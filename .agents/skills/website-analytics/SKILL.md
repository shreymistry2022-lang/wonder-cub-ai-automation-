# Website Analytics Skill

## Focus Areas
1. Monitor traffic referred by Instagram via `utm_source=instagram` and `utm_medium=organic_social`.
2. Measure click-through rate from Instagram bio / link stickers to `https://thewondercub.store/jungle-safari`.
3. Track key user events:
   - `page_view`
   - `view_item` (Jungle Safari bundle page)
   - `begin_checkout`
   - `purchase`
