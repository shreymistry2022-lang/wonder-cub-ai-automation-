# Daily Content Workflow

1. Read latest research (data/reports/, data/trends/).
2. Read historical performance (data/performance/, data/learning/).
3. Read products (config/products.yaml).
4. Invoke content-strategist -> generate five concepts.
5. Score them (config/scoring.yaml).
6. Select winner (highest final_score, respecting content_mix in
   config/content-pillars.yaml).
7. Invoke creative-director.
8. Invoke quality-checker.
9. Save draft to content/review/, set status REVIEW.
10. Do not publish.
